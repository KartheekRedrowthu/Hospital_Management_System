A full-stack hospital management system built with React, Node.js, and MySQL that supports role-based access for Admin, Doctor, Front Desk Operator, and Nurse.

**Features**:

Role-based login and dashboard

Patient registration, appointment booking, and room management

Doctor prescriptions, test handling, and discharge process

Nurse test result entry and reporting
